Smart Algorithm
ขั้นที่ 1 Smart Filtering

🔒 สถาปัตยกรรมการรักษาความปลอดภัย (AES-256-GCM Encryption)

Zero-Knowledge

สำหรับข้อสอบจำลองลับ (Secret Mock Exam 2569) ระบบใช้การเข้ารหัสระดับมาตรฐานกองทัพ เพื่อป้องกันไม่ให้นิสิตแกะดูเฉลยผ่านการ Inspect Code:

1

Build Time Encryption (Python Compiler)

เมื่อพบเคสที่มีรหัสผ่านใน Google Doc ระบบจะสร้าง Salt (16 bytes) และ IV (12 bytes) สุ่ม จากนั้น Derive Key ด้วย PBKDF2-HMAC-SHA256 (100,000 rounds) แล้วเข้ารหัสทั้งก้อน JSON ด้วย AES-256-GCM

2

Safe Metadata Masking

ในไฟล์ case-data-offline.js ข้อมูลชื่อโรค หัวข้อ และเฉลยจะถูกแทนที่ด้วยข้อความ 🔒 ล็อกด้วยรหัสผ่าน (Secret Mock) เพื่อความลับสูงสุด

3

Client-side Decryption (Web Crypto API)

เมื่ออาจารย์หรือผู้คุมสอบกรอกรหัสผ่านในหน้าเว็บ ฟังก์ชัน decryptCasePayload() จะใช้ Web Crypto API ในเบราว์เซอร์ถอดรหัสออกมาทันที โดยไม่ต้องส่งรหัสผ่านกลับไปที่เซิร์ฟเวอร์
