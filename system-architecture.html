🏛️ โครงการเตรียมสอบใบประกอบวิชาชีพเภสัชกรรม (RxCU84/85)
🏠 หน้าหลัก 📚 คลังข้อสอบ 🎮 ซ้อมสอบ OSPE

ℹ️ เกี่ยวกับระบบ & การทำงานของแพลตฟอร์ม

แพลตฟอร์มรวบรวมคลังข้อสอบและจำลองการสอบ OSPE สำหรับนิสิตเภสัชศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย ออกแบบด้วยเทคโนโลยี Offline-First เพื่อความเร็วสูงสุด 0ms ปลอดภัย และพร้อมใช้งานทุกที่ทุกเวลา

📊

1. แหล่งจัดเก็บข้อมูล (Data Sources)

ข้อมูลข้อสอบทั้งหมดได้รับการจัดเตรียมและควบคุมคุณภาพโดยคณะทำงานวิชาการโครงการเตรียมสอบฯ:

  • 1
    Google Sheets (CaseLibrary): ทะเบียนคลังข้อสอบ 350+ ข้อ จัดหมวดหมู่ กลุ่มโรค ผู้แต่ง และการเชื่อมโยงสถานี
  • 2
    Google Docs: เอกสารแม่แบบโจทย์ ข้อมูลผู้ป่วย อุปกรณ์ เกณฑ์ Checklist และเฉลยละเอียด
⚡

2. การทำงานออฟไลน์ 0ms (Offline-First)

ระบบถูกคอมไพล์ล่วงหน้าเป็นฐานข้อมูลในตัวเว็บเบราว์เซอร์ ทำให้นิสิตเข้าถึงข้อสอบได้ทันที:

  • 1
    โหลดทันที 0ms: ไม่ต้องรอโหลด API หรือฐานข้อมูลจากภายนอก เปิดเว็บปุ๊บพร้อมฝึกทำข้อสอบได้ทันที
  • 2
    รูปภาพฝังในตัว: รูปภาพประกอบข้อสอบทั้งหมดถูกแปลงเป็น Base64 เปิดดูได้แม้ไม่มีอินเทอร์เน็ต
🎮

3. ระบบจำลองสอบ OSPE อัจฉริยะ

ระบบสุ่มข้อสอบที่จำลองบรรยากาศห้องสอบจริงตามเกณฑ์ของสภาเภสัชกรรม:

  • 1
    สุ่มกระจายหัวข้อ: คัดกรองไม่ให้กลุ่มโรคซ้ำเกิน 2 สถานี และชื่อโรคไม่ซ้ำกัน เพื่อความหลากหลาย
  • 2
    สถานีต่อเนื่อง (Linked Cases): เคสที่ต้องทำต่อเนื่อง (เช่น ชั่ง ➔ ผสม) จะถูกจัดให้อยู่ติดกันเสมอ 100%
  • 3
    สถานีพัก (REST): คำนวณช่วงการพักตามรอบสอบจริง โดยไม่แทรกคั่นกลางเคสต่อเนื่อง
☁️

4. การเผยแพร่และโฮสติ้ง (Deployment)

เว็บไซต์ทำงานบนคลาวด์มาตรฐานระดับโลก มีความเสถียรและความปลอดภัยสูง:

  • 1
    GitHub Repository: จัดเก็บซอร์สโค้ดและควบคุมเวอร์ชันอย่างเป็นระบบ
  • 2
    Vercel Edge Network: Auto-deploy จาก GitHub อัตโนมัติ กระจายเซิร์ฟเวอร์แบบ CDN ทั่วโลก โหลดเร็ว ลื่นไหล ไม่ล่ม
  • 3
    Analytics & Performance: ตรวจวัดความเร็วและสถิติการใช้งานผ่าน Vercel Insights อย่างปลอดภัย

🔒 ความปลอดภัยและการรักษาความลับข้อสอบ (Security & Privacy)

สำหรับข้อสอบจำลองลับ (Secret Mock Exam) ข้อมูลจะได้รับการเข้ารหัสด้วยมาตรฐาน AES-256-GCM + PBKDF2 (100,000 rounds) และถอดรหัสผ่าน Web Crypto API ภายในเครื่องของผู้ใช้เมื่อได้รับรหัสผ่านที่ถูกต้องเท่านั้น มั่นใจได้ในความปลอดภัยของคลังข้อสอบ 100%
