# คู่มือการใช้งานระบบ Remote Compile & Push (GitHub Actions)
**ระบบคลังข้อสอบและแบบฝึกหัด PLE-CC (RxCU84/85)**  
**จัดทำโดย:** ประธานโครงการเตรียมสอบใบประกอบวิชาชีพ ปีการศึกษา 2569

---

## 1. ประโยชน์ของระบบ Remote Compile & Push
- ไม่ต้องเปิดคอมพิวเตอร์ส่วนตัว: สามารถสั่งอัปเดตระบบข้อสอบผ่านสมาร์ตโฟน แท็บเล็ต หรือคอมพิวเตอร์เครื่องใดก็ได้
- เลือกรันเฉพาะเคสที่ต้องการได้ (Selective Mode): ไม่จำเป็นต้องรอโหลด 340+ เคสทั้งหมด ประหยัดเวลาและทรัพยากร
- อัปเดตและดีพลอยอัตโนมัติ: ระบบจะดึงข้อมูลล่าสุดจาก Google Sheets และ Google Docs รวมไฟล์และ Push ขึ้น GitHub ซึ่งจะทริกเกอร์ Vercel ให้ Deploy หน้าเว็บจริงทันที

---

## 2. ขั้นตอนการใช้งานผ่าน GitHub บนเบราว์เซอร์ (มือถือ / คอมพิวเตอร์)

### ขั้นที่ 1: เข้าสู่หน้าระบบ GitHub Actions
1. เปิดเบราว์เซอร์และล็อกอิน GitHub
2. ไปที่ลิงก์ Repository ของโครงการ:
   https://github.com/thanadolnar-png/PLE-CC-Practice-Web-Page
3. คลิกแท็บ Actions ที่แถบเมนูด้านบน (หรือเข้าตรงที่ https://github.com/thanadolnar-png/PLE-CC-Practice-Web-Page/actions)

### ขั้นที่ 2: เลือกเวิร์กโฟลว์
1. ที่แถบเมนูด้านซ้าย (Actions list) ให้คลิกเลือก:
   Remote Compile and Push
2. จะสังเกตเห็นแถบสีฟ้าแจ้งเตือนทางขวาบนพร้อมปุ่ม:
   Run workflow

### ขั้นที่ 3: กำหนดตัวเลือกและกดสั่งรัน (Run workflow)
เมื่อคลิกปุ่ม Run workflow จะมีหน้าต่างเล็กๆ ปรากฏขึ้นมาให้กรอกข้อมูล:

1. Use workflow from:
   เลือก branch `main` (เป็นค่ามาตรฐานอยู่แล้ว)

2. เลือกโหมดการ Compile (filter_mode):
   - `all` : ดึงข้อมูลและคอมไพล์ทุกเคสทั้งหมดในระบบ (เหมาะสำหรับการ Rebuild ประจำสัปดาห์)
   - `cases` : ระบุรหัสเคสเจาะจง (เช่น ต้องการอัปเดตแค่เคสเดียวหรือ 2 เคส)
   - `keyword` : กรองตามชื่อเรื่อง, ชื่อโรค, หรือคำสำคัญ
   - `category` : กรองตามหมวดวิชา (`Clinic` หรือ `Product`)
   - `source` : กรองตามชุดข้อสอบหรือแหล่งที่มา (เช่น `2583`, `เล่มม่วง`, `Mock`)

3. คำค้นหา/รหัสเคส/หมวด (filter_query):
   - หากเลือกโหมด `all`: ช่องนี้ปล่อยว่างไว้ได้เลย
   - หากเลือกโหมด `cases`: พิมพ์รหัสเคส เช่น `OSPE-CL83M101` หรือถ้ามีหลายเคสให้คั่นด้วยวรรค เช่น `OSPE-CL83M101 OSPE-PD83M102`
   - หากเลือกโหมด `keyword`: พิมพ์คำสำคัญ เช่น `Dosage form` หรือ `Warfarin`
   - หากเลือกโหมด `category`: พิมพ์ `Clinic` หรือ `Product`
   - หากเลือกโหมด `source`: พิมพ์คำค้นหาแหล่งที่มา เช่น `2583` หรือ `เล่มม่วง`

4. ข้อความกำกับ Git Commit (commit_msg):
   ใส่ข้อความสั้นๆ ระบุว่าเราแก้ไขอะไร หรือปล่อยว่างไว้เพื่อใช้ค่ามาตรฐาน

5. คลิกปุ่มสีเขียว Run workflow:
   ระบบคลาวด์ของ GitHub จะเริ่มรันงานทันที (ใช้เวลาประมาณ 10-40 วินาที สำหรับเคสเดี่ยว และ 1-2 นาที สำหรับทุกเคส)

---

## 3. การตรวจสอบผลการทำงาน
1. หลังกด Run workflow ให้รีเฟรชหน้าเว็บ Actions จะเห็นรายการงานกำลังทำงาน (ไอคอนหมุนสีเหลือง)
2. เมื่องานเสร็จสิ้น ไอคอนจะเปลี่ยนเป็น เครื่องหมายถูกสีเขียว
3. เข้าไปตรวจสอบที่หน้าเว็บหลัก PLE-CC บน Vercel หรือกดรีเฟรชหน้าเคสนั้นๆ จะพบว่าเนื้อหาและรูปภาพได้รับการอัปเดตเป็นเวอร์ชันล่าสุดเรียบร้อยทันที

---

## 4. ความปลอดภัยและความถูกต้องของข้อมูล (Safety Mechanism)
- Smart Merge: หากสั่งคอมไพล์เฉพาะเคส ข้อมูลของเคสอื่นๆ ใน `case-details-offline.js` จะยังคงอยู่ครบถ้วน ไม่ถูกลบออก
- Secret Key Protection: รหัส Service Account ถูกจัดเก็บอย่างปลอดภัยใน GitHub Encrypted Secrets (`GCP_SA_KEY` / `COMPILE_AND_PUSH`) จึงไม่มีการรั่วไหลของรหัสผ่านในประวัติ Git
