# สมุดบันทึกประวัติการแก้ไขระบบ (PLE-CC System ChangeLogs)
โครงการเตรียมสอบใบประกอบวิชาชีพเภสัชกรรม (PLE-CC) ประจำปีการศึกษา 2569

โฟลเดอร์นี้จัดทำขึ้นโดยทีมงานฝ่ายบริหารและจัดการโครงการ (Poy เลขานุการโครงการ) 
เพื่อใช้รวบรวม บันทึก และติดตามประวัติการแก้ไขฟังก์ชัน โค้ดระบบ และการพัฒนาฟีเจอร์ต่างๆ 
ของแพลตฟอร์ม PLE-CC ไว้อย่างเป็นระบบ เพื่อให้ประธานโครงการและทีมงานสามารถย้อนดูประวัติการพัฒนาได้ตลอดเวลา

---

## สารบัญเอกสารในโฟลเดอร์นี้
1. MASTER_CHANGELOG.md : บันทึกสรุปประวัติการแก้ไขทั้งหมดตามลำดับเวลา (Master Index)
2. TEMPLATE.md : แบบฟอร์มมาตรฐานสำหรับการบันทึกการแก้ไขในครั้งถัดไป
3. 2026-10-09_Exam_Simulation_Upgrades.md : รายละเอียดการอัปเกรดระบบจำลองการสอบ OSPE ประจำวันที่ 9 ตุลาคม 2569

---

## ขั้นตอนการบันทึกการแก้ไขใหม่ (How to Log Changes)
เมื่อมีการแก้ไขโค้ดหรือเพิ่มฟีเจอร์ใหม่ ให้ดำเนินการดังนี้:
1. คัดลอกเนื้อหาจากไฟล์ TEMPLATE.md มาสร้างเป็นไฟล์ใหม่ในรูปแบบ:
   YYYY-MM-DD_ชื่อเรื่องการแก้ไข.md
2. ระบุรายละเอียดของปัญหา สาเหตุการเกิด ปัญหาที่แก้ไข และไฟล์ที่ได้รับผลกระทบ
3. เพิ่มรายการย่อในตารางสรุปของไฟล์ MASTER_CHANGELOG.md
4. ซิงค์ไฟล์ไปยัง Website/PLE CC Webpage/ChangeLogs และ Website_Backup เพื่อสำรองข้อมูลขึ้น GitHub
