## รายละเอียดปัญหาและวิธีการแก้ไข (Problem & Solution Breakdown)

### 1. ปัญหา: รายการ Diagnostics ปรากฏในเมนู Tools ของผู้เข้าสอบ
- อาการที่พบ: เมื่อผู้เข้าสอบกดปุ่ม Tools ประจำสถานี จะเห็นเมนู "ตรวจสอบระบบ & Log (Diagnostics)" และป้ายเตือนสีแดง (!) เมื่อมี Warning หรือ Error ในระบบ
- สาเหตุ: ฟังก์ชันตรวจสอบระบบเดิมถูกผูกติดไว้ในเมนูเครื่องมือส่วนกลาง ทำให้ผู้เข้าสอบทุกคนเข้าถึงได้
- วิธีแก้ไข:
  - ถอดรายการเมนู Diagnostics ออกจาก #unified-exam-tools-menu ให้เมนู Tools เหลือเพียง แชทสถานี (Station Chat) และ กระดาษทด (Scratchpad) เท่านั้น
  - ถอดกล่อง Modal #modal-ple-diagnostics ออกจากหน้าเว็บทั้งหมด

### 2. การรับประกันว่าระบบเก็บ Log ไม่กระทบการทำงานของฟังก์ชันอื่น (Zero-Impact Assurance)
- วิธีแก้ไข:
  - ปรับปรุง PleDiagnostics ให้ทำงานเป็น Headless Logger ในหน่วยความจำอย่างสมบูรณ์
  - ครอบคำสั่งทุกส่วนด้วย try ... catch เพื่อป้องกันไม่ให้เกิด Exception ใดๆ ที่จะไปขัดขวางการทำงานของระบบสอบ
  - การดักจับ console.error และ console.warn ยังคงเรียกฟังก์ชันดั้งเดิมของเบราว์เซอร์เสมอ ไม่ทำให้คอนโซลเสียการทำงาน
  - คืนค่า openDiagnosticsModal(), closeDiagnosticsModal() เป็นฟังก์ชันว่างที่ปลอดภัย เพื่อป้องกันข้อผิดพลาดกรณีมีโค้ดเก่าเรียกใช้งาน
  - ผู้ดูแลระบบสามารถตรวจสอบ Log สดผ่าน DevTools Console ด้วยคำสั่ง window.getPleLogs() ได้เมื่อจำเป็น

### 3. การจัดเก็บประวัติและการแก้ไขบน GitHub
- บันทึกการแก้ไขโค้ด ปัญหา สาเหตุ และแนวทางแก้ไขจะถูกจัดเก็บเป็นไฟล์ Markdown ในโฟลเดอร์ ChangeLogs/ และทำการ Commit/Push ขึ้นสู่ GitHub โดยตรง
