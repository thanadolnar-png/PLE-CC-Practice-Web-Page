## รายละเอียดปัญหาและการแก้ไขแยกตามหัวข้อ (Detailed Breakdown)

### 1. แก้ปัญหา Passcode เด้งถามซ้ำหลังห้องสอบออนไลน์เริ่มแล้ว (13:40 น. | Commit 3b4f496)
- อาการที่พบ: เมื่อผู้เข้าสอบหรือผู้ประเมินอยู่ในห้องสอบออนไลน์ แล้วห้องเริ่มสอบ หรือผู้ใช้รีเฟรชหน้าต่าง ระบบจะแสดงหน้าต่างถามรหัสผ่าน (Passcode) ซ้ำ ทำให้ถูกบล็อกไม่สามารถเข้าสู่หน้าข้อสอบได้
- สาเหตุ: ฟังก์ชันตรวจสอบสิทธิ์ใน exam-simulation.html ทำงานซ้ำทุกครั้งที่ตรวจพบการเปลี่ยนแปลงของห้อง โดยไม่ได้ตรวจสอบว่าห้องได้เข้าสู่สถานะเริ่มสอบแล้วหรือยัง
- วิธีแก้ไข: เพิ่มเงื่อนไขตรวจสอบสถานะห้อง หากห้องสอบเริ่มแล้ว (Running) หรือผู้ใช้เคยผ่านการตรวจสอบสิทธิ์แล้ว ระบบจะข้ามขั้นตอนการถามรหัสผ่านทันทีและนำเข้าสู่หน้าจอข้อสอบ

### 2. ปรับปรุงระบบล้างข้อมูลเก่าเมื่อเริ่มสอบใหม่ (14:00 น. | Commit 462adff)
- อาการที่พบ: เมื่อจบการสอบหรือกดยกเลิกการสอบ ข้อมูลเก่าเช่น Session และคะแนนสอบยังคงค้างอยู่ใน sessionStorage/localStorage ทำให้เมื่อจะเปิดสอบชุดใหม่ ระบบแอบดึงข้อมูลเก่ากลับมาแสดงผล
- สาเหตุ: ฟังก์ชัน restartSetup() เดิมไม่ได้ล้างกุญแจจัดเก็บข้อมูลห้องสอบย่อย (Cohort Session Keys) ออกอย่างสมบูรณ์
- วิธีแก้ไข: ปรับปรุงฟังก์ชัน restartSetup() ให้ล้าง Session Keys และสถานะของห้องทั้งหมดอย่างเด็ดขาด เคลียร์ Timer, Firebase Listener และคืนค่า SimState ทั้งหมดเป็นค่าเริ่มต้น พร้อมเพิ่มปุ่มรีเซ็ตด่วนด้านบน

### 3. แก้ไขระบบปรับแต่งสถานี (Adjust), ปุ่มทดเวลา (Timer Adjust), และเพิ่มระบบบันทึก Log (15:50 น. | Commit 3dcd8ee)
- ปัญหาระบบ Adjust สถานี:
  - อาการ: เมื่อกดปรับแต่งสถานีใน Adjuster แล้วเข้าสอบ ข้อสอบไม่แสดงผล
  - สาเหตุ: ข้อมูลสถานีที่ถูกปรับแต่งไม่ซิงค์กับตัวเลือกลำดับสถานีและจำนวนสถานีพัก ทำให้ระบบโหลดชุดข้อสอบผิดพลาด
  - วิธีแก้ไข: ปรับปรุงการนำเข้าข้อมูลสถานีที่ถูกปรับแต่ง (Hydration) ให้เชื่อมโยงกับตัวเลือกการจัดลำดับและสถานีพักอย่างแม่นยำ
- ปัญหาปุ่มทดเวลา/ลดเวลา:
  - อาการ: ปุ่มแสดงให้ทุกคนเห็นและกดได้ (ทั้งผู้สอบและผู้ประเมิน) และเมื่อกดแล้วเวลาจะรีเซ็ตกลับไป 04:00 แทนที่จะทดเวลาเพิ่ม
  - สาเหตุ: ตรรกะเดิมอัปเดตเฉพาะ timerStartedAt แต่ไม่ได้อัปเดต timerDuration ใน Firebase ส่งผลให้ Client คำนวณเวลาที่เหลือโดยหักลบกับค่าเริ่มต้นเดิม
  - วิธีแก้ไข: จำกัดสิทธิ์ปุ่มทดเวลาให้เห็นเฉพาะ Super Host เท่านั้น และปรับปรุงสูตรการคำนวณให้อัปเดตทั้ง timerDuration และ timerStartedAt พร้อมกัน ทำให้เวลานับถอยหลังจากค่าที่ทดจริงได้อย่างถูกต้อง
- เพิ่มระบบ PleDiagnostics (Live Log Viewer):
  - สร้างระบบดักจับ Error และ Warning ของเว็บ เก็บประวัติ 100 รายการล่าสุด
  - เรียกดูได้ผ่านเมนูเครื่องมือหรือกดคีย์ลัด Ctrl + Shift + L พร้อมปุ่มคัดลอก Log ทั้งหมด

### 4. ตรวจสอบความเชื่อมโยงของฟังก์ชันและการแยกข้อมูลผู้สอบ (16:08 น. | Commit a61f879)
- ปรับระบบการกดข้ามสถานี (Station Jump Navigation) และการสั่นกริ่งเปลี่ยนรอบให้ทำงานสอดคล้องกับตัวจับเวลา
- ในโหมด Carousel Rotation (แลปกริ๊งหมุนเวียน) ได้แยกพื้นที่เก็บข้อมูลคำตอบที่พิมพ์และคะแนนของแต่ละคนออกจากกัน เพื่อป้องกันไม่ให้ผู้สอบในแต่ละสถานีบันทึกข้อมูลทับกัน

### 5. แก้ไขแถบเวลา iPad, รูปแบบคะแนน Checklist, และเพิ่มระบบ Comment หลังสอบ (17:30 น. | Commit 95b2a64)
- แก้ปัญหาแถบเวลาเลื่อนหลุดใน iPad:
  - สาเหตุ: style.css กำหนด html, body { overflow-x: hidden !important; } ใน Media Queries ซึ่ง WebKit/Safari จะตัดการทำงานของ position: sticky
  - วิธีแก้ไข: เปลี่ยนเป็น overflow-x: clip !important บน html, body, .app-shell, .page-viewport และตั้งค่า top: 0 !important ร่วมกับ safe-area-inset-top
- ปรับรูปแบบรายการ Checklist:
  - ตัดคำว่า "ข้อย่อย" ออกทั้งหมด และเปลี่ยนลำดับเลขเป็นแบบลำดับขั้น เช่น "ข้อ 1:" และ "↳ 1.1:", "↳ 1.2:"
  - ตัดเครื่องหมายบวกและลบ (+ / -) ออกจากคะแนนทั้งหมด โดยแสดงเป็น "(X คะแนน)" หรือ "(X / Y คะแนน)"
  - ปรับสีและสัญลักษณ์ตามคะแนนจริง:
    - ข้อที่เลือกแล้วได้ 0 คะแนน: แสดงสีแดง "❌ เลือกข้อนี้ (0 คะแนน)"
    - ข้อหลักที่ได้ 0 คะแนน: แสดงสีแดง "❌ ไม่ได้คะแนน (0 / X คะแนน)"
    - ข้อที่ได้คะแนนบางส่วน: แสดงเครื่องหมายตกใจสีเหลือง ⚠️ ทั้งข้อหลัก "⚠️ ได้บางส่วน (X / Y คะแนน)" และข้อย่อย "⚠️ เลือกข้อนี้ (X คะแนน)"
    - ข้อย่อยที่ไม่ได้เลือก: แสดงเป็นสีเทากลาง ⚪ "(ไม่ได้เลือก)"
    - ปรับปรุงให้ตรงกันทั้งใน Accordion ผลสอบบนหน้าเว็บและระบบพิมพ์รายงาน OSPE
- เพิ่มระบบบันทึกข้อเสนอแนะหลังสอบ (Post-Exam Debrief Feedback):
  - เพิ่มช่อง Textarea ให้พิมพ์ Comment ได้ในทุกสถานีหลังสอบเสร็จ
  - ซิงค์แบบเรียลไทม์ระหว่างเพื่อนและผู้ประเมินผ่าน Firebase ในโหมดออนไลน์
  - ดึงข้อความ Comment ไปแสดงในเอกสารพิมพ์รายงานสรุปผล OSPE โดยอัตโนมัติ
