# Director's Treatment

## Director Brief
- Visual thesis: "The Monolithic Clinical Chamber" — An austere, precision-engineered flight deck for elite pharmacy clinical OSPE candidates, balancing absolute clarity with atmospheric cinematic authority.
- Signature technique 1: Monolithic Hairline Architecture (Subtle ambient top-lights, anodized titanium surfaces, and razor-fine 1px structural borders).
- Signature technique 2: Phosphor Diode State Signals (Emerald for vacant bays, Amber pulse for 5-minute countdown locks, Crimson for full capacity).
- Signature technique 3: Telemetric Monospace Overlay (High-legibility student ID telemetry and countdown timestamps using crisp monospace typography).
- Motion rules: Physics-grounded snappy easing (`cubic-bezier(0.16, 1, 0.3, 1)`), zero bouncy cartoon effects, subtle glow shifts on hover.
- Typography rules: Display headings in `Bai Jamjuree` (Semi-bold, letter-spaced), Body in `Inter`, Telemetry & Timestamps in `JetBrains Mono` / `Space Grotesk`.

## Site Cinematic Grammar
- Page-shell logic: Deep obsidian field (`#070a12`) hosting an architectural center console.
- Navigation posture: Frosted glass floating HUD bar with real-time operational status and legend indicators.
- Framing discipline: Grid columns locked to 12 temporal intervals with sticky date coordinates.
- Density cadence: Spacious command bar -> Dense high-information schedule matrix -> Clear monolithic protocol card.
- Recurring material layers: Smoked glass (`rgba(17, 24, 39, 0.75)`), dark titanium borders (`rgba(255, 255, 255, 0.08)`), and state glow apertures.
- Allowed composition families: Monolithic Slab, Tactical Grid Matrix, HUD Overlay Chamber.
- What may repeat: Monospace timestamps, hairline matrix borders, diode indicators.
- What must vary page to page: Unique modal depths, countdown urgency shaders, and hover coordinate tooltips.
- Demo uniqueness guardrail: Absolutely no default flat white bootstrap cards or generic pastel tags.

## Page Arc

### Page: Command & Booking Console (Home)
- Page-role scene: The Clinical Operating Chamber
- Page scene thesis: A single commanding view where any pharmacy student can instantly ascertain chamber availability, lock a practice slot, or confirm physical presence within 5 minutes.
- One big idea: The Calendar as a living tactical status matrix with realtime countdown telemetry and glowing diode feedback.
- Hero dominance statement: The schedule matrix commands the screen with high-contrast luminance and surgical grid lines, making empty vs occupied bays instantly identifiable from across the room.
- Restraint statement: No unnecessary animations or distracting decorative illustrations; every pixel conveys scheduling state or security protocol.
- Material thesis: Deep obsidian, frosted titanium, phosphor emerald, wallace amber, and laser crimson.
- Typography thesis: `Bai Jamjuree` for Thai authority, `Inter` for microcopy, and tabular numbers for temporal precision.
- Narrative arc: Status Reconnaissance -> Bay Selection -> Student Manifest Registration -> Real-time Check-in Telemetry -> Protocol Safeguard.
- Hero archetype: Monolithic Interactive Command Deck.
- Signature composition: Architectural Matrix with luminous status beacons and live pulsing check-in countdown diodes.
- Grid fallback test: Removing all styles leaves a strict, semantically logical 7x12 time-table and accessible action modal.
- Shared system holdback: Retain Google Apps Script backend bindings (`google.script.run`) flawlessly while supercharging the UI.
- UI exposure guardrail: No internal director metadata exposed in student-facing UI.
